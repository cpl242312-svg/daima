## 三、关键数学与经济含义核验

### 1. 设计与技术协同

沿用9月15日稿已经完成的软成本约束：设计最大化`A-D-Ψ`。这不是本轮新换模型，也没有恢复旧的硬上限作为主设定。正文式（1）—（3）补足内点存在、严格凹性、角点反应及互操作性全导数。

`s'=-Ψ_{sτ}/(D_{ss}+Ψ_{ss}-A_{ss})<0`需要正分母与`Ψ_{sτ}>0`；`φ'=φ_τ+φ_s s'>0`使用同一最优设计路径。附录A保留硬上限的备选表达，定义无约束解`s^0`，并明确约束切换点使用单侧导数。

协同选择以可转移支付下的双边联合净收益为目标。式（5）的分母`C_{kk}-B_{kk}>0`，故`k'=-C_{kφ}φ'/(C_{kk}-B_{kk})>0`。严格增加限于可调整的内点，不能无条件外推至零投入角点。

### 2. 耐受阈值与抵抗力

式（6）允许定制收益损失和协同收益并存。设计与协同建设成本在冲击实现前已经支付，是关系维持决策的沉没成本；前后期成本和收益须折算到共同计价时点，而不是把不同时间的金额直接相加。

式（7）保留原始冲击概率`p`，风险为`δ=p[1-F(φV)]`。式（8）分解为技术适应、客户专用价值损失和技术协同三个作用。式（9）为`φ'/φ+V'/V>0`，而非要求`V'>0`。

其“局部充要”表述限于`p>0`、`f(u*)>0`、`V>0`且冲击分布和终止基准固定。如果阈值附近密度为零，阈值上升不保证概率局部严格下降；若原始冲击率或外部选项也改变，则必须计入相应导数，不能继续照搬该结论。

### 3. 闭合搜寻及等待价值

保持已完成的两状态Bellman：成功状态满足`ρJ=π`；尚未重构状态最大化搜寻流量净收益。`J`在进入成功状态时计价，等待折现由Bellman处理。`W`内生，因此`x=J-W`不能当作外生常数。

正文式（12）—（15）保留唯一正根、最优努力和强度。固定成功收益及搜寻技术时，`x`下降、`W`上升，但接触回报改善仍使最优努力及到达强度提高。附录A2另给`J(τ)`变化时的公式；若成功收益随标准下降，必须再检验净效应，不能仅凭`J>0`推出强度上升。

有效成本系数`κ^R=γ/(λ²q²)`由达到给定强度所需的努力推得，没有再额外假设原始成本下降。它和转化效率是同一机制的等价表达。最优单位时间支出增加不等于成功前累计支出增加，正文与附录A3已分开解释。

### 4. 有限窗口、目的国与竞争风险

式（17）把重构指标与其概率分开：指标为是否首次成功，概率为`r^H=1-exp(-Hη*)`。固定强度需要短窗口内的标准效应、架构和搜寻参数平稳，且`H`只是观察期限，不是企业最优停止期限。附录A3保留时间变动强度的存活概率表达及适用边界。

附录B保留目的国有效暴露`z=τω`、阈值曲率、冲击密度导数和有限窗口饱和项。高契合度并不单凭`φ'>0`就必然带来更强概率效应。

附录C使用两类渠道共同等待价值、相同成功价值及首次到达竞争。新客户相对占比增加不能直接改写为其绝对概率增量必然超过原客户；成功价值不同时，现有共同价值差的比值消去不再成立。年度数据中两类关系同期出现也不能人为判断首次渠道。

## 四、符号和术语统一表

| 符号 | 统一含义 |
|---|---|
| `i、j、c、h` | 中国供应商、海外客户、客户国家、供应商行业；`h`不再表示到达强度 |
| `t` | 本次关系断裂的识别期/事件观察基点；不是搜寻持续时长 |
| `τ` | `Standard_{h,t-1}`，设计和关系转移前形成的行业环境 |
| `v、H、T_{ib,t}` | 自事件基点开始的持续时间、观察窗长、首次成功等待时长 |
| `b` | 企业断裂事件标识，不是单条旧关系编号 |
| `s、k` | 非兼容的客户专用设计强度、连续双边关系型技术协同深度 |
| `φ、q(φ)` | 技术互操作性水平、候选接触转成有效关系的概率，不混用 |
| `V` | 关系维持决策时点、相对固定终止基准的双边联合经营价值 |
| `J、W、x` | 进入成功状态的私人价值、尚未重构的私人状态价值、二者内生差额`J-W` |
| `ρ、π` | 贴现率、成功状态的增量净利润流 |
| `e、λ、γ` | 单位时间努力、候选接触效率、原始努力成本系数 |
| `η、θ` | 有效到达强度、简写系数`λ²q²/γ`；强度不是概率 |
| `p、I、u、F、f` | 原始冲击概率、发生指标、条件冲击负担及其分布与密度 |
| `u*、δ、r^H` | 耐受阈值、本次断裂概率、已断裂事件的窗口内首次重构概率 |
| `ω、z、Φ、U` | 附录B的预定目的国契合度、有效标准暴露、约化互操作性、约化阈值 |
| `R、N、P_ℓ^H` | 附录C的原客户/替代客户渠道，以及各渠道为首次成功的概率 |

术语统一为“技术互操作性—关系型技术协同—匹配效率—首次有效重构”，没有把全文改成Nature式英文，也没有为润色改变已有经济含义。学术审查与语言技能主要用于约束结论强度、减少重复、分清假设与经验支持；文档技能用于可编辑公式和分页检查。
