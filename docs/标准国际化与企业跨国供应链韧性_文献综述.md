# 一、文献综述与研究述评

## （一）标准国际化的贸易与企业效应

标准既是规定产品性能、接口、检测方法与生产流程的技术规则，也是连接不同国家生产者和使用者的制度性基础设施。相较于仅在国内适用的技术规范，国际标准能够为跨国交易提供共同的技术语言，其经济效应主要体现为降低信息不对称、提高产品兼容性和减少重复适配成本。早期研究发现，标准对国际贸易具有双重影响：一方面，统一标准可以传递质量信息、促进规模经济并降低跨境交易成本，从而扩大贸易；另一方面，严格或国别化的标准也可能形成固定合规成本和技术性壁垒，对企业进入国际市场产生抑制作用（Swann等，1996；Gandal和Shy，2001；Fontagné等，2015）。因此，标准的贸易效应并不只取决于标准数量或严格程度，更取决于不同市场之间能否形成协调一致的技术要求。Clougherty和Grajek（2014）关于ISO 9000扩散的研究进一步表明，国际标准的贸易促进效应具有明显的国家和企业异质性。

在中国情境下，相关研究已从“采用国际标准”和“参与国际标准制定”两个方向拓展了标准国际化的内涵。前者强调将国际通行的技术要求转化为国内生产规范，后者则强调中国企业和行业通过承担ISO、IEC技术机构职务、取得正式表决权以及提出国际标准提案等方式参与全球技术规则形成。现有经验研究普遍发现，标准国际化能够降低企业面对国内外不同技术规则时的制度转换成本，并通过质量信号、技术创新和国内外生产体系衔接改善企业出口表现。韩剑等（2024）发现，标准国际化能够通过质量信号传递、创新激励及内外贸一体化提升出口产品质量；李文文和郎丽华（2025）从技术标准协调的角度指出，标准协调通过成本互补效应和需求扩张效应促进出口产品质量升级；王艳艳等（2025）基于中国上市公司数据发现，国际标准采用效率能够提高出口收入占比，扩展出口国家和产品范围，并降低企业进入国际市场的生产率门槛。王孝松等（2026）进一步表明，国际标准采用有助于降低内外贸规则转换成本，促进企业由单一内贸向内外贸一体化转型。

与“引进来”相对应，参与国际标准制定体现了中国技术规则“走出去”的过程。杨志浩和洪俊杰（2025）表明，标准开放能够通过协作、竞争和信息渠道促进本土企业创新，并产生上下游溢出效应；马皓巍和王如雪（2026）发现，标准国际化既提高企业出口进入概率，也强化出口中的主动学习，从而推动技术追赶；李川川等（2026）则从标准国际协调出发，揭示其对企业出口扩张及出口广度的促进作用。上述研究共同说明，标准国际化不仅影响产品能否进入海外市场，还可能改变企业与境外交易对象之间的信息传递、技术适配和持续合作条件。

然而，现有文献大多将出口额、出口概率、出口产品质量、市场范围或技术创新作为结果变量，关注的是企业国际化的平均绩效。即使有关市场拓展和内外贸一体化的研究已涉及企业可服务市场的扩大，也较少进一步识别：国际标准所形成的互操作性和质量可识别性，能否延长具体跨国供应关系的存续时间；当原有关系中断后，能否帮助企业恢复原关系或转向其他海外客户。因而，将标准国际化研究推进到跨国供应关系的“存续—中断—重构”层面，是理解其供应链效应的重要延伸。

## （二）跨国供应链韧性、关系断裂与供应链重构

供应链韧性通常是指供应链在冲击发生前预防风险、冲击发生时维持关键功能，以及冲击发生后恢复或调整网络结构的能力。裴建锁等（2025）据此将产业链供应链韧性概括为风险预防力、冲击抵抗力和恢复重构力。对企业跨国供应链而言，韧性并不等同于供应商或客户数量的静态增加，而应表现为具体交易关系在冲击下能否继续存在，以及关系断裂后企业能否及时建立可行的新关系。由此，关系层面的断裂概率刻画供应链抵抗力，中断后的恢复与替代则刻画恢复重构力。

生产网络文献为理解供应链断裂的经济后果提供了理论基础。由于上下游投入存在互补性，单个企业或局部环节受到的冲击可能沿生产网络向其他企业传导并产生总量效应（Acemoglu等，2012）。投入品越专用、替代来源越有限，企业越难在短期内调整采购或销售关系，冲击的持续时间和传导强度也越大（Barrot和Sauvagnat，2016）。日本大地震的经验证据进一步表明，即使冲击最初集中于少数地区，也可能通过供应关系扩散到未直接受灾的企业，凸显关系持续性和替代能力在供应链韧性中的作用（Carvalho等，2021）。

围绕企业如何配置韧性，理论研究主要形成了保护性投入、供应来源多元化和产品兼容性三条思路。Antràs等（2017）指出，企业在不同国家的投入采购决策具有相互依赖性，增加一个来源地会改变其他来源地带来的边际收益。Grossman、Helpman和Lhuillier（2023）进一步比较了本土化与多元化策略，指出企业会在生产成本与中断风险之间权衡，供应来源多元化并非在所有情形下都能被简单地替代为回流生产。Grossman、Helpman和Sabal（2024）将保护能力投资和多层供应链联系选择内生化，揭示单个企业的韧性投入会通过网络外部性影响其他环节，分散决策可能导致供应链整体韧性不足。Ferrari和Pesaresi（2026）则进一步从“专业化—兼容性”权衡解释韧性：面向特定交易对象的深度专业化能够提高单次匹配收益，却可能缩小可兼容交易对象的集合；当互补投入和搜寻摩擦并存时，过度专业化会降低中断后的替代能力，而最低兼容性标准有助于纠正这一外部性。该框架说明，供应链重构不仅取决于潜在伙伴是否存在，也取决于企业产品能否嵌入新客户的技术体系。

关系型数据的发展使上述理论可以在企业—交易伙伴层面得到检验。丁浩员等（2024）基于中国上市公司与境外交易伙伴数据，将原有供应关系由存在转为消失界定为供应链断裂，并考察中断后企业能否通过原关系恢复、同国客户替代或跨国客户转移实现重构。研究发现，贸易政策冲击会提高供应链断裂风险，而产品不可替代性、较低契约成本和长期合作有助于维持关系；在关系中断后，搜寻效率和供应链多元化能力则有助于重构。李磊等（2025）沿用关系层面的识别思路，发现专利出海能够通过合作、声誉和技术风险缓释提高跨国供应链的抵抗力、恢复力和长期发展能力。这类研究将供应链韧性的观察对象由企业总体经营结果推进到具体供应关系，但其核心解释变量主要是贸易政策冲击或企业知识资产。

另一些文献从企业能力和外部制度条件解释供应链安全。段文奇等（2023）发现，贸易便利化能够降低进口成本并促进供应来源多元化和本土化；何茜茜等（2024）表明，工业机器人应用可通过资本深化、技术创新、生产率和数字化提高制造业产业链供应链韧性；沈国兵和沈彬朝（2025）发现，企业数字化通过降低搜寻成本、增强创新能力和改善议价能力促进供应链多元化。与本文最为接近的是沈国兵和沈彬朝（2024）关于高标准贸易协定的研究，该文发现更深层次的协定条款能够改善双边制度环境并降低全球供应关系断裂风险。不过，高标准贸易协定反映的是涵盖投资、竞争、知识产权等内容的广义制度安排，尚不能回答技术标准本身如何通过产品兼容性和质量识别影响关系稳定与中断后重构。

## （三）标准国际化影响跨国供应链韧性的逻辑衔接

将上述两支文献结合起来，标准国际化与跨国供应链韧性之间存在三个相互关联的作用环节。

第一，标准国际化提高技术互操作性，降低既有关系因需求或技术要求变化而断裂的概率。中国供应商与海外客户建立关系后，双方往往围绕产品接口、性能参数、检验方法和数据编码进行专用性适配。若行业标准与国际通行规则不一致，海外客户的技术要求发生变化时，供应商需要承担重复设计、检测和认证成本；若企业按照国际标准组织生产，产品与客户技术体系之间的兼容程度更高，企业便能够以较低成本吸收技术调整。国际标准由此延长既有产品的适用范围，降低一般性冲击转化为关系终止的可能性。这一逻辑将标准协调文献所强调的规则转换成本，与Barrot和Sauvagnat（2016）所强调的投入专用性及Ferrari和Pesaresi（2026）所强调的兼容性直接联系起来。

第二，标准国际化强化质量可识别性和关系治理，提升既有关系的持续价值。跨国交易双方存在地理距离、信息不对称和验证成本，海外客户难以完全观察供应商的生产能力和履约质量。采用和参与制定国际标准能够向客户传递稳定、可验证的质量信号，并促使企业在研发、生产和检验环节形成一致的质量控制程序（韩剑等，2024）。质量信息更透明不仅有助于企业首次进入国际市场，也会降低既有客户的监督和重新议价成本，增强双方继续合作的预期收益。因而，标准国际化同时通过技术适配和质量治理提高关系抵抗力，经验上应表现为企业—海外客户关系的断裂概率下降。

第三，标准国际化扩大兼容客户集合并降低市场转换成本，提高中断后的恢复与重构能力。供应关系中断后，企业能否重构取决于接触潜在客户的效率以及接触后达成可行交易的概率。国际标准把原本分散的技术规格转化为可跨企业、跨市场识别的公共技术语言，能够减少潜在客户筛选、样品验证和产品再设计成本，使同一产品适配更多海外客户。这既有利于企业修复与原客户的关系，也有利于其与原客户所在国的其他客户建立关系；当国际标准在多个国家得到采用时，其作用还会跨越国别市场，帮助企业转向其他国家客户。王艳艳等（2025）发现国际标准采用能够扩大企业出口国家和产品范围，马皓巍和王如雪（2026）及李川川等（2026）发现标准国际化能够促进出口进入和市场扩张，这些结果为“兼容客户集合扩大”提供了间接证据；丁浩员等（2024）关于搜寻效率与中断后关系重构的发现，则为其与供应链恢复重构之间的联系提供了经验基础。

需要指出的是，标准国际化并不必然单向提高韧性。遵循国际标准可能要求企业支付设备改造、认证和持续合规成本，短期内挤压用于备份产能或关系维护的资源；产品兼容性提高也可能降低供应商的不可替代性，使海外客户更容易更换供应商。此外，针对特定客户的深度专业化虽会降低通用兼容性，却可能通过提高关系租金和转换成本稳定原有关系。因此，标准国际化对供应链韧性的净效应，取决于互操作性、质量识别和市场转换成本下降所带来的收益，能否超过合规成本与客户替代便利化产生的反向作用。这一竞争性机制使相关命题具有可证伪性，也要求经验研究分别考察关系断裂和中断后的不同重构路径，而不能以单一综合指标替代。

## （四）研究述评与本文切入点

综上，标准国际化文献已经较为充分地识别了其对出口进入、产品质量、国际市场范围、内外贸一体化和技术创新的影响，供应链韧性文献也从网络冲击、关系专用性、来源多元化、保护性投资和搜寻匹配等角度解释了供应关系的稳定与调整。然而，两类研究之间仍存在三个值得推进的环节。

其一，现有标准国际化研究主要考察企业国际化的规模和质量效应，对已形成跨国供应关系能否抵御冲击关注不足。出口额或出口范围增加并不必然意味着供应关系更加稳定，因而需要直接观察同一供应商—客户关系是否持续。

其二，既有供应链韧性研究较少将国际技术标准视为影响关系专用性和替代空间的基础制度。贸易协定、数字化、创新和自动化能够改善企业外部环境或内部能力，但国际标准具有统一技术接口、形成质量信号并扩大产品兼容范围的独特功能，其作用不能被一般制度开放或企业能力变量完全替代。

其三，关系断裂后的恢复与重构具有不同经济含义。恢复原客户关系反映既有专用性投资的保存，与同国其他客户建立关系反映区域市场内的替代能力，转向其他国家客户则更能反映跨市场兼容性和地理分散能力。只有区分这些路径，才能判断标准国际化究竟主要巩固原有关系，还是提高企业摆脱特定客户和特定国别市场约束的能力。

基于此，本文以中国上市公司作为境内供应商，以境外客户作为跨国供应关系的另一端，将行业—年份层面的标准国际化程度与企业—海外客户—关系—年份数据相匹配。在结果变量上，本文以关系在当期存在而下一期消失所形成的断裂指标衡量供应链抵抗力；在发生断裂的样本中，进一步以是否形成后续关系衡量恢复重构力，并区分原客户恢复、同国其他客户替代和跨国客户转移。该研究设计把标准国际化的互操作性与质量识别效应落实到关系存续和关系转换上，从而在标准国际化研究与跨国供应链韧性研究之间建立可检验的微观联系。
