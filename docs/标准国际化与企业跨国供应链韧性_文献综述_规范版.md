# 文献综述与研究述评

## （一）标准国际化与企业国际化经营

标准对国际贸易的影响并非单一的成本效应，而是技术协调、信息传递与合规约束共同作用的结果。Swann等（1996）基于英国行业数据发现，标准活动能够影响贸易表现，且具有本国特征的标准同样可能促进出口。这意味着标准的经济作用不能简单归结为国际标准优于国内标准，而应考察其具体功能及跨市场适用条件。Clougherty和Grajek（2014）进一步以ISO 9000的跨国扩散为对象，发现共同语言与质量信号有助于促进双边贸易，但合规成本也可能使标准普及程度较低的国家处于不利地位。两项研究共同提示，标准既可能降低交易双方的协调难度，也可能形成进入门槛，其净效应取决于技术规则和采用条件。

在此基础上，标准协调研究将分析重点由标准的数量与覆盖程度推进到不同国家技术要求的一致性。Schmidt和Steingress（2022）利用跨国自愿性产品标准数据发现，标准协调通过减少国别适配成本促进贸易，其企业层面的出口销售增益主要体现于规模较大的出口商。与此不同，Fontagné等（2015）考察被提交至世界贸易组织特定贸易关注机制的限制性卫生与植物卫生措施，发现这类措施抑制企业出口参与和出口规模，且较大企业受到的负面影响相对较弱。两类证据并不矛盾：前者研究共同规则减少重复适配的作用，后者研究具有贸易限制性的监管要求。因而，不能将限制性技术措施的贸易效应直接视为标准国际化的效应，也不能把产品标准协调与质量管理认证视为完全相同的技术机制。

中国情境下的研究进一步将标准国际化与企业微观表现联系起来。韩剑等（2024）从国际标准采用和中国标准“走出去”两个角度构建指标，发现标准国际化通过质量信号、技术创新和内外贸一体化等渠道促进出口产品质量提升。王艳艳等（2025）以中国上市公司为对象，将行业层面的国际标准采用效率与企业出口行为相匹配，发现其能够促进国际市场拓展，相关作用涉及生产率门槛降低和内外贸一体化企业数量增加。这些研究为行业技术规则影响企业国际化经营提供了经验依据，同时表明行业共同标准环境与单个企业的认证、采标行为需要在概念和测度上加以区分。

上述研究分别从贸易规模、出口质量、市场进入及拓展解释了标准的经济后果，但这些结果尚不能直接回答具体跨国供应关系能否持续。即使企业出口额增加或进入更多市场，原有客户关系仍可能频繁更替；企业退出某个出口市场，也不等同于其中某一条供应商—客户关系断裂。因此，将标准国际化的影响落实到关系存续以及断裂后的后续交易，有助于区分国际化经营的扩张效应与供应链韧性效应。这一延伸需要以关系状态变化为分析对象，而不能仅将已有贸易绩效结论替换为“韧性提升”的表述。

## （二）供应链冲击、关系断裂与恢复重构

供应链韧性研究强调企业对扰动的准备、响应和恢复能力，而非单纯追求平稳时期的经营效率。Ponomarov和Holcomb（2009）从跨学科视角整理这一概念，指出韧性涉及冲击应对以及恢复至原有或更好运行状态的能力。生产网络研究则揭示了为何个别企业的冲击可能具有更广泛的经济后果。Barrot和Sauvagnat（2016）利用自然灾害识别企业特有冲击，发现受影响供应商会向客户传导产出损失，且投入品专用性较高时这一影响更强。Carvalho等（2021）基于东日本大地震的证据表明，冲击能够沿上下游联系传导至直接和间接交易伙伴。这些研究说明，交易联系及其替代条件是理解冲击传导的重要基础；不过，产出损失和网络传播本身并不必然意味着观测到的双边关系永久终止。

关系数据的应用使供应链调整能够进一步落实到具体交易伙伴的变化。丁浩员等（2024）利用FactSet Revere数据追踪中国上市公司的海外供应链关系，发现美国对华加征关税提高了关系断裂风险，而产品不可替代性、较高的契约成本及长期合作基础有助于维持关系。该文还发现，信息搜寻效率和多元化布局能力与断链后的重构相联系，由此将冲击下的关系存续和后续调整纳入同一研究视野。相较于仅观察企业总体出口变化，这一研究路径能够区分原有交易受阻和企业重新获得交易机会，为本文分别考察抵抗力与恢复力提供了经验参照。

关系稳定与调整能力之间并不存在简单的对应关系。较高的关系专用性可能增加终止合作的代价，因而有助于维持原关系，却也可能使断裂后的替代更加困难。丁浩员等（2024）关于契约成本的分析主要立足于“断裂成本”，不能据此推断新增合作的实施成本越高越有利于韧性。对本文而言，降低技术沟通和方案验证的边际成本，可以通过促进合作深化增加关系收益；既有关系的终止代价则属于另一类权衡。区分这些成本的发生阶段和经济含义，是将合作深化与断裂后重构纳入统一分析的前提。

## （三）关系投入、专业化与技术兼容性

关于韧性的理论研究进一步将关系保护与网络结构视为企业决策的结果。Elliott等（2022）在供应网络形成模型中引入多来源采购和关系强化投资，揭示企业如何权衡投入成本与连接可靠性，以及内生形成的网络为何仍可能具有脆弱性。Grossman等（2024）将事前保护性投入、供应联系形成及纵向议价纳入多层供应链框架，强调个体投入会对其他企业产生外部性，私人激励与社会最优配置因而可能不同。这些研究为“关系可靠性可以通过投入改善”提供了理论基础，但其研究对象并非行业标准国际化，也不能被直接解释为国际标准促进双边联合研发或股权合作的经验证据。

与投入保护相衔接，Ferrari和Pesaresi（2026）从产品专业化选择解释供应链恢复能力。其核心权衡是：中间品生产者提高专业化程度能够增加匹配中的增加值，却会缩小与其产品兼容的最终生产者集合；当生产依赖多种互补投入且替代存在搜寻摩擦时，正常时期的生产率收益可能伴随较弱的冲击后恢复能力。该文还讨论了兼容性标准的政策含义。这一框架将研究重点推进到“哪些交易对象在技术上能够成为替代者”，表明潜在伙伴数量本身不足以决定有效替代空间，产品与交易对象之间的技术适配条件同样重要。

上述两类理论为本文提供了互补的微观基础。关系投入研究解释企业为何愿意付出资源维护合作，专业化与兼容性研究则解释这种合作为何可能难以迁移至其他对象。将二者用于行业标准国际化，需要明确本文的延伸：一方面，共同技术规则可能降低新增合作的实施难度，同时改善既有关系吸收技术需求变化的能力；另一方面，互操作性提高可能使候选客户更容易转化为可行交易，从而减少达到同等有效匹配强度所需的搜寻资源。这里的有效成本下降与匹配效率提高是同一技术改善的不同表述，不宜重复设为两项独立收益，也不意味着企业最优搜寻总支出必然减少。这些关于标准作用的具体关系属于本文提出并检验的机制，而非相关文献已经确立的共同结论。

## （四）研究述评与本文切入点

综合上述文献，可以将本文的研究位置界定为三方面的衔接。首先，标准国际化研究已经提供了关于技术协调、出口质量和市场拓展的证据，进一步需要区分其对交易扩张和交易持续性的影响；后者不能由前者机械推得。其次，供应网络研究揭示了关系专用性、保护性投入和兼容条件的作用，但将这些机制用于中国供应商的海外客户关系，需要明确行业共同规则如何进入企业决策，而不是把标准作为一个直接降低风险的外生标签。最后，断裂与重构研究已经确立了观察关系动态变化的可行路径，但既有关系是否延续与断链后是否获得后续交易具有不同的条件样本和观察单位，二者应分别识别。

基于此，本文以中国上市供应商与海外客户的交易为对象，将行业标准国际化视为影响技术互操作性的共同规则环境，考察其如何改变关系由存续转为断裂、以及断裂后实现重构的概率。在既有关系阶段，重点分析互操作性改善和合作深化的保护作用，并保留非兼容性专业化受约束可能造成的定制收益损失；在断链后阶段，重点分析兼容条件如何影响有效搜寻成本与后续交易形成。经验上，抵抗力对应双边关系的断裂，恢复力对应企业断裂事件后给定窗口内至少一次原客户恢复或替代客户形成，不将未断裂关系视为重构失败，也不将一次新客户形成重复归属于多条旧关系。本文由此连接标准国际化的技术协调功能与跨国供应关系的生命周期，形成关于合作深化和有效搜寻成本的可检验预测，而不预设标准国际化对全部企业及各类冲击均具有无条件的韧性提升效应。
