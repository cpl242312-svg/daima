# 变量定义与研究设计

## 关系断裂

抵抗力以中国供应商与海外客户的双边关系为观察单位。对期初已有关系，若其在 \(t\) 期存在、\(t+1\) 期消失，则 \(Break_{ijct}=1\)，否则取0。断裂归记于 \(t\) 期，重构窗口从确认断裂后开始。原始数据中的关系标识保留在数据键中，不与理论中的专业化程度 \(s_{ij}\) 混用。关系消失与数据覆盖变化的识别须依据实际数据字段核验。

## 企业断裂事件

恢复力以企业—断裂事件 \((i,b)\) 为观察单位。同一企业同一观察期确认的多条断裂合并为一个起始事件，并冻结该事件起始时的中断客户集合。在给定窗口 \(H\) 内，若恢复该集合中的任一原客户，或首次建立新的海外客户关系，则 \(Reconstruct^H_{ib}=1\)。起始时仍然存续的其他客户及其订单增加不构成重构；一次事件成功不等于全部旧关系或销售规模均已恢复。

## 非重叠风险窗口

同一企业同时只保留一个重构风险期。首个有效重构发生或既定窗口结束时关闭该风险期，下一事件只能由风险期关闭后续期的新断裂触发。风险期内新增的断裂不再建立平行观察窗，也不追溯扩大起始事件的原客户集合。这样，同一后续客户不会同时用于解释多个尚未关闭的断裂事件。

采用年度数据时，仅使用能够由年度关系记录确定的先后顺序，不推断不可观察的年内交易时点。在确认断裂的年度，其他新客户形成若无法判定在断裂之前或之后，不直接视为断裂后的重构。观察窗长度、年度纳入边界和可用历史范围须在具体数据处理中保持统一。

## 未发生重构与右删失

在 \(H\) 期内已经观察到有效重构的事件可记为1；完整观察 \(H\) 期仍未重构时记为0。观察窗口不完整且尚未重构的事件为右删失，不能直接赋值为0。未发生断裂的关系不进入重构事件样本，也不被赋值为重构失败。

“首次建立新海外客户”应依据连续可用的客户历史识别，并与原客户恢复区分。数据库左端之外的客户历史通常不可观察，因而历史覆盖长度和首次出现的识别口径需在数据说明中交代，不能将数据库中的首次出现无条件等同于企业历史上首次交易。

## 与机制及理论单位的对应

合作深化机制使用断裂前的双边合作状态；不能用断裂后的合作反推事前关系保护。有效搜寻成本指实现同等有效匹配强度所需的资源成本，不等于实际搜寻总支出，也不能直接以新客户数量等重构结果替代。

理论的单一互操作性指标基于事件内受影响产品共享核心技术架构的简化。若事件涉及多种异质产品架构，理论比较静态应理解为技术构成给定时的方向判断，不能未经定义将某条客户关系的专业化程度直接赋予整家企业。

以上为从理论正文移出的变量构造口径，尚未据原始数据实施或验证，不代表已经完成样本生成与实证估计。
