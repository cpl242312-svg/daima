## 二、逐项修改

### 1. 关系设计与企业事件的映射

**原问题** → 关系层面的专用设计直接进入企业事件的单一互操作性。

**为何被质疑** → 上市公司可能经营不同业务，其他业务新增客户不自动构成原业务重构。

**如何修改** → 引入架构／业务单元g，在事前客户集合上固定权重，定义S*_{ig}=Σ_jw_{ijg}s*_{ijg}，再以φ̄_{ig}=φ(S*_{ig},τ)概括技术基础。每条研究关系在基准中依托一个主要架构；事件b及重构候选限定在同一g，关系价值和协同仍可因客户而异。

**理论含义** → 固定权重使φ̄′=φ_τ+φ_sΣ_jw_{ijg}s*′_{ijg}>0。这是代表架构的聚合假设，并非数据恒等式，也未联立优化全部客户设计外部性。权重变化会引入额外导数项。

**实证影响** → 无法识别g时，企业事件仅是经验近似。建议检查同期单条海外客户断裂事件，并尽可能匹配业务；单条断裂不能完全排除跨业务误配。不用断裂后客户份额定义事前权重。

### 2. 互操作性的定义与符号

**原问题** → φ^τ容易误读为幂，“接口互操作性”又不足以对应测试、认证等标准内容。

**为何被质疑** → 最优水平、偏导与全导数混淆，技术机制与指标不匹配。

**如何修改** → 改用φ̄(τ)，定义为“技术兼容与合规可迁移性”，简称技术互操作性；区分φ_s、φ_τ、φ̄′与候选转化概率q(φ̄)。

**理论含义** → 涵盖接口、参数、架构调整及测试和认证资料复用；法律意义上的认证互认仍取决于认可规则。

**实证影响** → 需用标准内容论证指标对应，不能因为扩大定义便将标准数量、参与制定或后续引用直接视为互操作性测量。

### 3. 专用设计附加成本Ψ

**原问题** → Ψ_{sτ}>0容易被理解为“国际标准提高所有定制的绝对成本”。

**为何被质疑** → 标准也可能降低定制成本，原表述显得为得到s′<0而设定。

**如何修改** → 改为相对于共同架构，维持非标准体系的附加／机会成本，说明接口维护、专用验证和规模经济损失。相关资源在正常阶段承诺并折算为建设成本。

**理论含义** → 正交叉偏导是相对边际代价的条件性假设，不是制度强制或普遍事实；专用体系同样受益时可能不成立。内点、凹性及角点边界继续保留。

**实证影响** → 需行业与标准内容支撑，允许效应较弱或相反的适用环境，不能将假设写成已验证事实。

### 4. 外部选择改善与主动换客

**原问题** → 基准固定终止收益；直接在已经相对终止基准计量的V上再减绝对外部收益会双重扣减。

**为何被质疑** → 更易匹配可能诱发主动换客，且联合价值与私人价值不能混用。

**如何修改** → 附录A4设V=G−O₀、O=O_abs−O₀。O是相对同一固定基准的增量联合外部收益。在V−O>0时，u*_O=φ̄(V−O)，一般条件为φ̄′/φ̄+(V′−O′)/(V−O)>0。基准O≡0；固定外部收益水平已归入O₀。

**理论含义** → 主动换客是可能抵消保护作用的竞争力量，H1a保持条件性。V−O≤0时可能无冲击退出，原风险式及对数条件不再适用。O不直接等于事件层面的私人等待价值W。

**实证影响** → 不能将全部断裂解释为被动受损；需谨慎辨别主动升级。此扩展未联立识别外部选择，也未解决退出内生性。

### 5. 非技术性终止与观察误差

**原问题** → 技术型断裂不足以解释全部消失，但披露与覆盖变化又不是真实终止。

**为何被质疑** → 将经济终止和漏报放在同一个μ中，缩放公式不再有相应经济含义。

**如何修改** → 附录A5中μ仅表示独立的真实非技术性终止，δ_all=1−(1−μ)(1−δ)。固定μ时导数为(1−μ)δ′；变化时增加μ′(1−δ)。不称其为观察概率，除非记录准确完整。

**理论含义** → 固定独立渠道只缩小概率边际效应；μ随标准变化时方向不确定。主动换客若已由O解释，不再独立重复计入。永久退出者可能不满足恢复的正参与价值。

**实证影响** → 分清真实退出、客户破产、覆盖中断与实体映射错误；缺失或删失不能机械编码为断裂。

### 6. 连续技术协同与离散代理

**原问题** → 有无合作记录被当成连续协同深度的精确测量。

**为何被质疑** → 二元标签不能量化边际成本；主体与日期也可能不对应原供应关系。

**如何修改** → 保留连续k、可转移支付下的双边优化及k′推导；将代理限制集中于第五节。

**理论含义** → k′>0是可调整内点下的理论结果，不等同于已求解具有固定形成成本的二元合作模型，更不是对离散记录的无误差测量假设。

**实证影响** → 核验联合研发、技术合作、技术许可的双方、日期及内容。形成概率的证据应写“支持”“与渠道一致”，不能称已精确识别dk*/dτ或C_{kφ}。

### 7. 匹配效率与实际搜寻费用

**原问题** → 目标强度成本下降、努力增加与财务总费用下降容易混淆。

**为何被质疑** → 效率提升可诱导更多投入；再外生降低γ可能重复计入同一收益。

**如何修改** → 保留γe²/2、η=λeq(φ̄)及闭合Bellman，由固定目标强度反推κ^R=γ/(λ²q²)，不改变γ。

**理论含义** → κ^R′/κ^R=−2q′/q<0是同一匹配技术的成本表达。固定成功价值下W上升、x下降，但e*与η*仍上升。附录区分单位时间、未贴现累计与财务费用。

**实证影响** → H3不预测笼统的实际总费用下降。销售费用、等待时间、新客户数量不能自动当作独立成本或转化效率证据。

### 8. 恢复样本选择与参与条件

**原问题** → 断裂样本的结果容易被表述为总体效应，仅凭J>0也不能保证全部比较静态。

**为何被质疑** → 标准改变断裂者构成；成功收益变化也影响搜寻激励。

**如何修改** → H1b前明确成功收益与技术可比条件，保留附录A2的J(τ)扩展；第五节解释给定事件的模型比较与实际选择的区别。

**理论含义** → 这是已断裂后的条件转移预测。风险模型、多状态模型和IPW需要额外假设，不自动解决选择或行业变量内生性。

**实证影响** → 明确风险集、目标总体与识别条件；条件回归系数不能自动视为条件因果效应，更不能称为总体无条件因果效应。

### 9. 标准、协同与断裂时序

**原问题** → 年度滞后不一定保证标准先于真实协同决策。

**为何被质疑** → 年末信息或未来权重可能倒灌至早期解释变量。

**如何修改** → 保持τ≡Standard_{h,t−1}。有日期按真实排序；仅年度数据时补充Standard_{h,t−2}→TechCoop_{ij,t−1}→Break_{ijct}的机制时序检查。

**理论含义** → 滞后说明预定信息集，不是工具变量，也不自动排除反向因果。

**实证影响** → 核验发布、实施、合作开始及权重可得日；二期滞后是待实施的稳健性思路，不是已完成的识别结果。

### 10. 年度快照与快速恢复漏记

**原问题** → 保守编码可能漏掉快恢复，但不能一般断言“估计偏保守”。

**为何被质疑** → 快恢复还可能令断裂本身不入样；起算点与窗口改变影响总体。

**如何修改** → 保留不臆定同年先后、优先真实日期及右删失要求，偏误结论改为条件性。在相同潜在风险集、窗口及无成功误记下，可写r_obs=r_true−m；还需m′≥0，概率边际效应才可能低估真实促进作用。

**理论含义** → 这一风险差条件不能直接推广到Logit系数或风险比，一般测量加选择偏误方向未定。

**实证影响** → 报告同年不明、窗口不足与覆盖缺失的处理，不能将尾部事件统一赋零。

### 11. 目的国与竞争风险扩展

**原问题** → 多市场共享架构不能同时由每个国家的一维暴露决定；新客户相对份额变化也不等于绝对增量排序。

**为何被质疑** → 忽略曲率、概率饱和、共同设计及不同成功价值，会产生过强预测。

**如何修改** → 附录B限定单一预定目的国架构，保留曲率、密度及饱和项；附录C保留共同W、相同成功价值和首次到达竞争。

**理论含义** → 两项结果均是条件性扩展，不新增无条件异质性假说。

**实证影响** → 目的国暴露在断裂前确定，不能用成功后的客户国家倒推；两种关系同年出现时不能臆造首个渠道。

### 12. 结构与语言

**原问题** → 重复辩护、测量细节和符号条件削弱理论主线。

**为何被质疑** → 章节容易成为审查日志，数学与经验解释混杂。

**如何修改** → 保留五节正文；代理、时序和选样集中于第五节；外部选择及非技术终止置于附录。假说用经济语言，数学条件由相邻命题承载。

**理论含义** → 正文组织机制与方向，附录交代证明及边界；不以复杂度替代贡献。

**实证影响** → 后续保持同一术语与H1a/H1b/H2/H3，不能单独摘出假说却省略其适用条件。
