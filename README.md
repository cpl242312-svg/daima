研究对象为中国上市供应商与海外客户的关系演化。理论主线固定为行业标准国际化提高技术互操作性，进而通过适应能力改善与合作深化降低既有关系断裂概率，并通过有效搜寻成本下降促进断裂后的关系重构。第一阶段 Break 保持双边关系单位；第二阶段 Reconstruct^H 改为不重叠的企业—断裂事件，避免一条替代客户关系被重复归因为多条旧关系分别恢复。这是理论和变量口径修订，尚未实施原始数据重构。

规范版保留三个连续命题和 H1a/H1b、H2、H3：两个主效应假说分别对应断裂与条件重构，两项机制对应双边合作深化和有效搜寻成本。保留阶段性最优决策与局部比较静态，不将其表述为全生命周期联立优化。抵抗力依据净阈值条件，不要求关系价值必然上升；合作采用可转移支付下的联合剩余选择；搜寻采用固定原始成本与一般匹配概率 q(φ)，由同一技术内生推出有效成本下降，不将实际总搜寻支出下降作为预测。

本轮统一了 q(φ) 在到达强度、努力、有效成本及重构概率中的使用，将搜寻目标解释为给定资本化价值差时的 Bellman 努力选择项。V、ΔV 等为价值量；K(e) 与 K^R 为单位时间成本，与 hΔV 保持相同量纲。首次定义 s_ij、k_ij，并补充短期技术刚性及事件内共同架构的简化假设。q 的下标 φ 表示对互操作性求导，与对 τ 的全导数撇号区分。二次搜寻成本与 u/φ 仅为基准参数化，一般化的方向结论仍保留内部解及净效应条件。恢复力比较静态继续保持接触效率、原始成本参数和正续接价值差给定。

事件非重叠、风险期关闭、窗口内新增断裂、右删失及年度时序细节已从理论正文移到上述变量定义文件。该文件只规定后续数据处理口径，尚未生成或验证实证样本。

四篇参考文献已按原始发布机构或期刊信息核对。Ponomarov与Holcomb（2009）用于韧性概念，Ferrari与Pesaresi（2026）用于专业化、兼容性与替代搜寻，Grossman等（2024）用于事前投入，Elliott等（2022）用于关系投入与连接失效。标准约束、合作成本和具体断裂规则是本文设定，不表述为上述文献已经证明的结论。
