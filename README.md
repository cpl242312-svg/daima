# 行业标准国际化与中国企业跨国供应链韧性

## 当前理论基准

自2026年9月6日起，第二章《理论模型与研究假说》以后述文件为唯一基准。后续文字修订、公式校对与实证对应均在此基础上进行。

- [基准版正文（Markdown）](docs/标准国际化与企业跨国供应链韧性_第二章_基准版.md)
- [基准版正文（Word 原生可编辑公式）](docs/标准国际化与企业跨国供应链韧性_第二章_基准版_公式编辑器.docx)

研究对象为中国上市供应商与海外客户的双边供应关系。理论主线固定为行业标准国际化提高技术兼容性，进而通过合作深化降低既有关系断裂概率，并通过搜寻成本下降和匹配效率提高促进断裂后的关系重构。

基准版保留两个命题和两个研究假说，分别对应 Break 与条件性 Reconstruct^H。全文采用阶段性最优决策和状态转移的局部比较静态；专业化和合作投入具有明确的内部解条件，抵抗力命题保留合作收益覆盖定制损失的充分条件，恢复力比较静态保持客户接触效率与正续接收益差给定。

四篇参考文献已按原始发布机构或期刊信息核对。Ponomarov与Holcomb（2009）用于韧性概念，Ferrari与Pesaresi（2026）用于专业化、兼容性与替代搜寻，Grossman等（2024）用于事前投入，Elliott等（2022）用于关系投入与连接失效。标准约束、合作成本和具体断裂规则是本文设定，不表述为上述文献已经证明的结论。
